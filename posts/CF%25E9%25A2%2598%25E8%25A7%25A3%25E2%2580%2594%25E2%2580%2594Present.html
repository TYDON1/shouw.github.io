B. Present 解题思路 ​

核心问题分析 ​

题意干净得不能再干净：给你一个长度为 nnn 的数组 aaa，让你求所有两两之和的异或

⨁1≤i<j≤n(ai+aj)\bigoplus_{1 \le i < j \le n} (a_i + a_j) 1≤i<j≤n⨁​(ai​+aj​)

也就是把 (n2)\binom{n}{2}(2n​) 个无序对的和全部异或起来，输出这个值。

数据范围是 n≤4×105n \le 4\times 10^5n≤4×105，ai≤107a_i \le 10^7ai​≤107。两两配对一共有大约 8×10108\times 10^{10}8×1010 对，直接枚举所有对当场去世。但是注意到异或是逐位独立的——异或结果的第 iii 位，只取决于有多少个对的和在第 iii 位上是 111。如果这样的对数是偶数，异或抵消，第 iii 位就是 000；如果是奇数，第 iii 位就是 111。

所以问题瞬间被拆成了 262626 个独立的小问题（ai≤107<224a_i \le 10^7 < 2^{24}ai​≤107<224，两数之和 <225< 2^{25}<225，枚举到第 252525 位足矣）：对每一位，求出有多少个对的和在这一位上是 111，看它的奇偶。 突破口就在这儿。

1. 只看低位：第 kkk 位的事，跟高位一毛钱关系都没有 ​

要判断 ai+aja_i + a_jai​+aj​ 的第 iii 位（这里复用源码的循环变量 iii 表示当前位）是不是 111，我们其实完全不关心它高于第 iii 位的部分。加法的进位只会从低位往高位传，高位的值传不回来。

于是对当前正在处理的第 iii 位，我们把每个数都对 2i+12^{i+1}2i+1 取模，只保留它的最低 i+1i+1i+1 位：

cpp
for (int j = 1; j <= n; ++j) {
    b[j] = a[j] % (1LL << (i + 1));
}
sort(all(b));

取模之后每个 bj∈[0,2i+1)b_j \in [0, 2^{i+1})bj​∈[0,2i+1)，因此任意两数之和 bi+bj∈[0,2i+2−2]b_i + b_j \in [0, 2^{i+2} - 2]bi​+bj​∈[0,2i+2−2]。我们只在这个被砍短的世界里数对子，对第 iii 位的真实情况丝毫不影响——因为更高的位本来就被加法的进位"隔离"在外面了。

2. 第 iii 位为 111 的和长什么样？两段区间一网打尽 ​

现在 s=bi+bjs = b_i + b_js=bi​+bj​ 落在 [0,2i+2−2][0, 2^{i+2}-2][0,2i+2−2] 里，我们要问：sss 的第 iii 位什么时候是 111？

把 sss 按第 iii 位为 111 来枚举它可能的取值区间。第 iii 位是 111，意味着 sss 写成二进制时那一位点亮，对应到数值上就是两段连续区间：

s∈[ 2i, 2i+1−1 ]或s∈[ 3⋅2i, 2i+2−2 ]s \in [\,2^i,\ 2^{i+1}-1\,] \quad\text{或}\quad s \in [\,3\cdot 2^i,\ 2^{i+2}-2\,] s∈[2i, 2i+1−1]或s∈[3⋅2i, 2i+2−2]

第一段是"第 iii 位是 111、第 i+1i+1i+1 位是 000"（数值在 2i2^i2i 到 2i+1−12^{i+1}-12i+1−1）；第二段是"第 iii 位是 111、第 i+1i+1i+1 位也是 111"（数值从 3⋅2i3\cdot 2^i3⋅2i 起，上界卡在和的最大可能值 2i+2−22^{i+2}-22i+2−2）。由于和最大不超过 2i+2−22^{i+2}-22i+2−2，更高的位根本到不了，这两段就把"第 iii 位为 111"的情况收得严严实实。

对应到代码里那行漂亮的异或：

cpp
int cnt = tp(1LL << i, (1LL << (i + 1)) - 1) ^ tp(3LL << i, (1LL << (i + 2)) - 2);
if (cnt) {
    ans |= 1LL << i;
}

tp(x, y) 返回的是"和落在 [x,y][x,y][x,y] 内的对数的奇偶"。两段区间各自数一遍奇偶，再异或起来，得到的就是"第 iii 位为 111 的对数的总奇偶"。是奇数（结果为 111）就把答案的第 iii 位点亮。

3. tp 函数：排序 + 双指针，数出落在区间里的对数 ​

tp(x, y) 要数的是有多少个无序对 (i,j)(i, j)(i,j) 满足 bi+bj∈[x,y]b_i + b_j \in [x, y]bi​+bj​∈[x,y]。bbb 已经排好序，这就是经典的双指针套路：

cpp
auto tp = [&] (int x, int y) -> int {
    if (x > y) return 0;
    int num = 0;
    for (int i = n, l = 1, r = 1; i >= 1; --i) {
        while (l <= n && b[i] + b[l] < x) l++;
        while (r <= n && b[i] + b[r] <= y) r++;
        num += r - l - (l <= i && i < r);;
    }
    return num >> 1 & 1;
};

我们让外层固定一个 bib_ibi​（从大到小扫），用两个指针找出"能和 bib_ibi​ 凑出和在 [x,y][x,y][x,y] 范围内"的那一段 bbb：

  • l 是第一个使 bi+bl≥xb_i + b_l \ge xbi​+bl​≥x 的位置（再小和就低于下界了）；
  • r 是第一个使 bi+br>yb_i + b_r > ybi​+br​>y 的位置（即合法区间的右开端点）。

于是与 bib_ibi​ 搭配合法的下标区间是 [l,r)[l, r)[l,r)，里面有 r−lr - lr−l 个。这里有个精妙的细节：随着外层 iii 从 nnn 递减、bib_ibi​ 单调变小，要凑够下界 xxx 需要更大的搭档，所以 lll、rrr 这两个指针全程只增不减，整轮均摊下来是 O(n)O(n)O(n) 的，不会退化。

- (l <= i && i < r) 这一手是剔除自己跟自己配对的情形：如果下标 iii 本身就落在合法区间 [l,r)[l, r)[l,r) 里，说明 bi+bib_i + b_ibi​+bi​ 也被算进去了，但我们只要 i≠ji \ne ji=j 的对，得减掉它。

最后注意：上面这样数，每个无序对 (i,j)(i, j)(i,j) 会在"外层取 iii"和"外层取 jjj"时各被统计一次，所以 num 是真实对数的两倍。num >> 1 还原成无序对数，再 & 1 取奇偶返回。整个 tp 是一趟 O(n)O(n)O(n) 的扫描（外加输入已排序）。

4. 把账算清楚：总复杂度 ​

外层枚举 262626 个位，每个位要：对 bbb 数组取模重填（O(n)O(n)O(n)）、排序（O(nlog⁡n)O(n\log n)O(nlogn)）、跑两次 O(n)O(n)O(n) 的 tp。所以每位的瓶颈是那次排序，总复杂度

O(26⋅nlog⁡n)O\big(26 \cdot n \log n\big) O(26⋅nlogn)

n=4×105n = 4\times 10^5n=4×105 时，26⋅nlog⁡n26 \cdot n\log n26⋅nlogn 大约是 4×1084\times 10^84×108 量级，常数小、333 秒时限，稳稳通过。整个思路的灵魂就是：异或逐位独立 → 每位只看低位 → 取模后排序数对的奇偶，环环相扣，一气呵成。

CPP 代码实现 ​

cpp
// B. Present

#include <bits/stdc++.h>
#include <ext/pb_ds/assoc_container.hpp>
#include <ext/pb_ds/tree_policy.hpp>
#define lg(x) (63 - __builtin_clzll(x))
#define all(x) (x).begin(), (x).end()
#define low_bit(x) ((x) & (-x))
#define pb push_back
#define db long double
#define int long long
#define sz(x) (int)x.size()
#define endl "\n"

using namespace std;
using namespace __gnu_pbds;

struct custom_hash {
    static uint64_t splitmix64(uint64_t x) {
        x += 0x9e3779b97f4a7c15;
        x = (x ^ (x >> 30)) * 0xbf58476d1ce4e5b9;
        x = (x ^ (x >> 27)) * 0x94d049bb133111eb;
        return x ^ (x >> 31);
    }
    size_t operator()(uint64_t x) const {
        static const uint64_t FIXED_RANDOM = chrono::steady_clock::now().time_since_epoch().count();
        return splitmix64(x + FIXED_RANDOM);
    }
};

template<typename K, typename V> 
using hash_map = gp_hash_table<K, V, custom_hash>;
template<typename T> 
using ordered_set = tree<T, null_type, less<T>, rb_tree_tag, tree_order_statistics_node_update>;
template<typename T> 
using ordered_multiset = tree<T, null_type, less_equal<T>, rb_tree_tag, tree_order_statistics_node_update>;

void solve() {

    int n;
    cin >> n;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; ++i) cin >> a[i];
    vector<int> b(n + 1);
    int ans = 0;
    
    auto tp = [&] (int x, int y) -> int {
        if (x > y) return 0;
        int num = 0;
        for (int i = n, l = 1, r = 1; i >= 1; --i) {
            while (l <= n && b[i] + b[l] < x) l++;
            while (r <= n && b[i] + b[r] <= y) r++;
            num += r - l - (l <= i && i < r);;
        }
        return num >> 1 & 1;
    };

    for (int i = 0; i <= 25; ++i) {
        for (int j = 1; j <= n; ++j) {
            b[j] = a[j] % (1LL << (i + 1));
        }
        sort(all(b));
        int cnt = tp(1LL << i, (1LL << (i + 1)) - 1) ^ tp(3LL << i, (1LL << (i + 2)) - 2);
        if (cnt) {
            ans |= 1LL << i;
        }
    }
    cout << ans << endl;

}

signed main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t;

    while (t--) {
        solve();
    }
    
}
