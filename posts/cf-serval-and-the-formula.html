C. Serval and The Formula 解题思路 ​

核心问题分析与数学转化 ​

本题要求找到一个非负整数 kkk，使得：

(x+k)+(y+k)=(x+k)⊕(y+k)(x+k) + (y+k) = (x+k) \oplus (y+k) (x+k)+(y+k)=(x+k)⊕(y+k)

  • 位运算性质： 对于任意非负整数 a,ba, ba,b，都有 a+b=(a⊕b)+2(a&b)a+b = (a \oplus b) + 2(a \mathbin{\&} b)a+b=(a⊕b)+2(a&b)。

  • 条件转化： 题目中的等式 (x+k)+(y+k)=(x+k)⊕(y+k)(x+k) + (y+k) = (x+k) \oplus (y+k)(x+k)+(y+k)=(x+k)⊕(y+k) 等价于 2((x+k)&(y+k))=02((x+k) \mathbin{\&} (y+k)) = 02((x+k)&(y+k))=0。即：

    (x+k)&(y+k)=0(x+k) \mathbin{\&} (y+k) = 0 (x+k)&(y+k)=0

    这意味着 x+kx+kx+k 和 y+ky+ky+k 在二进制表示下，没有任何一位同时为 1。

1. 变量代换与简化 ​

不妨设 x≤yx \le yx≤y（若 x>yx > yx>y 则交换）。 令 A=x+kA = x+kA=x+k，则 y+k=y−x+x+k=(y−x)+Ay+k = y - x + x + k = (y-x) + Ay+k=y−x+x+k=(y−x)+A。 设差值 D=y−xD = y - xD=y−x。

我们的目标转化为找到一个 AAA（且 A≥xA \ge xA≥x），使得：

A&(A+D)=0A \mathbin{\&} (A + D) = 0 A&(A+D)=0

最后求出 k=A−xk = A - xk=A−x。

特殊情况： 如果 x=yx = yx=y，则 D=0D=0D=0，条件变为 A&A=0⇒A=0A \mathbin{\&} A = 0 \Rightarrow A=0A&A=0⇒A=0。但题目给定 x≥1x \ge 1x≥1，且 A=x+k≥1A = x+k \ge 1A=x+k≥1，因此 AAA 不可能为 0，故此时无解，输出 -1。

2. 构造策略 (利用进位消除) ​

我们要构造一个数 AAA，使得它和 A+DA+DA+D 没有公共的 1。 观察加法进位的特性：如果 AAA 的某一位是 1，且 DDD 的对应位也是 1，那么相加时该位会变成 0 并产生进位。

核心思路： 我们找到 DDD 的最高有效位 (MSB)，设其位置为 ppp（即 2p2^p2p）。

  1. 构造 AAA： 让 AAA 从第 ppp 位开始，一直到更高的位（比如第 40 位），全部置为 1。低于第 ppp 位的全部置为 0。
    • AAA 的形式：...11111000... （最低的 1 在第 ppp 位）。
    • DDD 的形式：...00001xxx... （最高的 1 在第 ppp 位）。
  2. 验证 A&(A+D)=0A \mathbin{\&} (A+D) = 0A&(A+D)=0：
    • 在第 ppp 位： AAA 是 1，DDD 也是 1。相加 1+1=10(2)1+1=10_{(2)}1+1=10(2)​，结果位为 0，向 p+1p+1p+1 位进 1。
    • 在第 p+1p+1p+1 位及以上： AAA 依然是 1，DDD 在这些位全是 0（因为 ppp 是 DDD 的最高位）。加上进位，1+0+1=10(2)1+0+1=10_{(2)}1+0+1=10(2)​，结果位为 0，继续向高位进 1。
    • 结论： 这种连锁反应会使得 A+DA+DA+D 在所有 AAA 为 1 的位置上都变成了 0。而在 AAA 为 0 的低位上，A+DA+DA+D 等于 DDD，两者自然没有交集。

3. C++ 代码实现细节 ​

代码中使用 std::bitset 方便地处理二进制串。 需要注意的是 bitset::to_string() 生成的字符串，索引 0 对应的是最高位。

  1. 计算 D=y−xD = y - xD=y−x。
  2. 将 DDD 转为 bitset 字符串，找到第一个 '1' 的位置（即最高位）。
  3. 构造 AAA 的字符串：从最高位开始直到 DDD 的最高位位置，全部填 '1'。
  4. 将构造的字符串转回 long long 得到 AAA。
  5. 输出 k=A−xk = A - xk=A−x。

由于 AAA 的构造方式保证了其值远大于 DDD，且通常大于 xxx，所以计算出的 kkk 为非负数。

cpp
#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

void solve() {

    ll data_one, data_two;
    cin >> data_one >> data_two;

    // 保证 data_one <= data_two
    if (data_one > data_two) {
        swap(data_one, data_two);
    } else if (data_one == data_two) {
        // x = y 时，(x+k) & (x+k) = x+k，不为0（因x>=1），无解
        cout << -1 << endl;
        return;
    }

    ll target = data_two - data_one; // 差值 D

    // 使用 bitset 处理二进制，大小 40 足够覆盖 10^9 和构造出的答案
    bitset<40> bits_target(target);
    string bits_target_string = bits_target.to_string();

    // 初始化构造的 A 的 bitset，初始全 0
    bitset<40> bits_ans(0);
    string ans_string = bits_ans.to_string();

    // 找到 target (D) 最高位的 1 在字符串中的下标
    // 注意：to_string 后，下标 0 是最高位 (MSB)
    size_t index_data = bits_target_string.find('1');
    
    // 构造 A：将 A 的最高位到 D 的最高位对应位置全部置 1
    // 逻辑上相当于构造了一个掩码：111...100...
    if (index_data != string::npos) {
        for (int i = 0; i <= index_data; i++) {
            ans_string[i] = '1';
        }
    }

    // 将构造的二进制字符串转回数值 A，计算 k = A - x
    ll ans_val = stoll(ans_string, nullptr, 2);
    ll k = ans_val - data_one;

    cout << k << endl;

}

int main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t;
    cin >> t;

    while (t--) {
        solve();
    }

}
