F. Choose a Square 解题思路 ​

核心问题分析 ​

题意：平面上有 nnn 个点，第 iii 个点在 (xi,yi)(x_i, y_i)(xi​,yi​)，权值为 cic_ici​（可以是负数）。要求选一个正方形，边平行于坐标轴，且左下角和右上角都落在直线 y=xy = xy=x 上，四个角都是整点。

得分 = 正方形覆盖（含边界）的所有点的权值和 −-− 正方形的边长。边长允许为 000。求最大得分，并输出方案。

n≤5×105n \le 5\times10^5n≤5×105，坐标 ≤109\le 10^9≤109，∣ci∣≤106|c_i| \le 10^6∣ci​∣≤106，时限 666 秒。

1. 先把"正方形"这个二维的壳剥掉 ​

左下角在 (l,l)(l, l)(l,l)、右上角在 (r,r)(r, r)(r,r)，正方形就是 [l,r]×[l,r][l, r] \times [l, r][l,r]×[l,r]。一个点 (x,y)(x, y)(x,y) 被覆盖，当且仅当

l≤x≤r且l≤y≤rl \le x \le r \quad \text{且} \quad l \le y \le r l≤x≤r且l≤y≤r

这两个条件可以合并成一句话：

l≤min⁡(x,y)且max⁡(x,y)≤rl \le \min(x, y) \quad \text{且} \quad \max(x, y) \le r l≤min(x,y)且max(x,y)≤r

于是每个点就退化成了一维数轴上的一条线段 [min⁡(xi,yi), max⁡(xi,yi)][\min(x_i,y_i),\ \max(x_i,y_i)][min(xi​,yi​), max(xi​,yi​)]，而"点被正方形覆盖"就等价于"这条线段被区间 [l,r][l, r][l,r] 完整包含"。二维一下子塌成了一维——这是这道题的第一层，也是最重要的一层化简。

目标函数变成：

max⁡l≤r(∑[Li,Ri]⊆[l,r]ci  −  (r−l))\max_{l \le r} \Big( \sum_{[L_i, R_i] \subseteq [l, r]} c_i \;-\; (r - l) \Big) l≤rmax​([Li​,Ri​]⊆[l,r]∑​ci​−(r−l))

2. 离散化 + 一个哨兵 ​

坐标高达 10910^9109 但只有 2n2n2n 个不同值，直接离散化。有两个容易漏的细节：

  • 要把 000 也塞进候选坐标里（题目允许 x1=y1=0x_1 = y_1 = 0x1​=y1​=0）；
  • 要额外塞一个比所有坐标都大的哨兵值。因为最优解可能是"什么都不选"（当所有点权值都是负的时候，答案应该是 000）。如果最大坐标处恰好有一个负权点，那在原有的候选值里就找不到一个"能放下空正方形"的位置。多加一个哨兵就能保证空正方形一定可选，答案下界稳稳是 000。
cpp
vals.pb(0);
sort(all(vals));
vals.erase(unique(all(vals)), vals.end());
vals.pb(vals.back() + 1);   // 哨兵：保证"空正方形"永远是合法方案

3. 从右往左扫 lll，把"线段生效"变成区间加 ​

现在要同时优化 lll 和 rrr 两个变量。经典做法：固定一个，用数据结构维护另一个。

我们从大到小枚举 lll（也就是从右往左扫）。当 lll 减小到某个点的 Li=min⁡(xi,yi)L_i = \min(x_i, y_i)Li​=min(xi​,yi​) 时，这个点的"左端条件"就满足了，此后只要 r≥Rir \ge R_ir≥Ri​ 它就会被覆盖。也就是说：

扫到 l=Lil = L_il=Li​ 的时刻，把 cic_ici​ 加到所有 r≥Rir \ge R_ir≥Ri​ 的候选位置上。

这正是一次区间加。所以把每个点挂到它的 LiL_iLi​ 上，扫描线扫过去逐个触发：

cpp
for (int i = m - 1; i >= 0; i--) {
    for (auto [r_now, val] : g[i]) {
        sgt.update(1, 0, m - 1, r_now, m - 1, val);  // 对 r >= R_i 的位置全部加上 c_i
    }
    ...
}

4. 线段树里到底存什么 ​

线段树的下标是候选的 rrr。在位置 jjj 上，我们希望存的是

(当前 l 下，选 r=valsj 时的权值和)−valsj\Big(\text{当前 } l \text{ 下，选 } r = vals_j \text{ 时的权值和}\Big) - vals_j (当前 l 下，选 r=valsj​ 时的权值和)−valsj​

也就是把 −r-r−r 提前塞进初值里，这样它就能跟后续的区间加自然地叠在一起：

cpp
void build(int v, int l, int r, vector<int>& vals) {
    if (l == r) { d[v] = {-vals[l], l}; return; }   // 初值就是 -r
    ...
}

于是查询区间 [l,m−1][l, m-1][l,m−1] 的最大值（只有 r≥lr \ge lr≥l 才是合法正方形），再补上一个 +l+l+l，就是当前这个 lll 能拿到的最好得分：

cpp
auto cur = sgt.query(1, 0, m - 1, i, m - 1);
if (cur.first + vals[i] > ans) {
    ans = cur.first + vals[i];
    ans_l = vals[i];
    ans_r = vals[cur.second];
}

注意线段树节点存的是 pair<int, int>——不仅要最大值，还要取到最大值的那个下标，因为题目要求输出方案。pair 的默认比较恰好是先比 first 再比 second，直接 max 就行，不用手写比较函数。

5. 为什么这样一定不重不漏 ​

值得停下来确认一件事：扫到 lll 时，线段树位置 jjj 上累加的，恰好是所有满足 Li≥lL_i \ge lLi​≥l 且 Ri≤valsjR_i \le vals_jRi​≤valsj​ 的点的 cic_ici​ 之和。

  • Li≥lL_i \ge lLi​≥l：因为区间加是在扫到 LiL_iLi​ 那一刻才触发的，lll 还没扫到的点根本没被加进去；
  • Ri≤valsjR_i \le vals_jRi​≤valsj​：因为区间加的范围是 [Ri,m−1][R_i, m-1][Ri​,m−1]，只有 j≥Rij \ge R_ij≥Ri​ 的位置才吃到这份贡献。

两个条件合起来正好是"线段 [Li,Ri][L_i, R_i][Li​,Ri​] 被 [l,valsj][l, vals_j][l,valsj​] 完整包含"。完美对应。

6. 复杂度 ​

离散化 O(nlog⁡n)O(n \log n)O(nlogn)；扫描线过程中每个点触发恰好一次区间加，共 nnn 次；每个 lll 做一次区间最值查询，共 O(n)O(n)O(n) 次。单次线段树操作 O(log⁡n)O(\log n)O(logn)，总计

O(nlog⁡n)O(n \log n) O(nlogn)

n=5×105n = 5\times10^5n=5×105 时大概 10710^7107 级别的线段树操作，666 秒时限非常宽裕（这么长的时限估计是给常数大的写法留的活路）。

回头看这道 ∗2400*2400∗2400 的题，难点其实分布得很均匀：先是"正方形覆盖 ⇒\Rightarrow⇒ 线段包含"这一步降维，然后是"扫描线让 lll 单调、把点的生效变成区间加"，最后是"把 −r-r−r 揉进线段树初值"这个小技巧——三步都不算特别难，但少任何一步都写不出来。另外别忘了那个哨兵坐标，不然会在"全是负权点"的数据上挂掉，这种边界才是真正的隐形杀手。

CPP 代码实现 ​

cpp
// F. Choose a Square

#include <bits/stdc++.h>
#define lg(x) (63 - __builtin_clzll(x))
#define all(x) (x).begin(), (x).end()
#define low_bit(x) ((x) & (-x))
#define pb push_back
#define db long double
#define int long long
#define sz(x) (int)x.size()
#define endl "\n"

using namespace std;

struct SGT {

    int n;
    vector<pair<int, int>> d;   // {最大值, 取到最大值的下标}
    vector<int> tag;

    SGT(int n) : n(n) {
        d.assign(4 * n + 1, {0, 0});
        tag.assign(4 * n + 1, 0);
    }

    void build(int v, int l, int r, vector<int>& vals) {
        if (l == r) {
            d[v] = {-vals[l], l};   // 初值 -r，后续区间加自然叠上去
            return;
        }
        int mid = (l + r) >> 1;
        build(v * 2, l, mid, vals);
        build(v * 2 + 1, mid + 1, r, vals);
        d[v] = max(d[v * 2], d[v * 2 + 1]);
    }

    void push(int v, int l, int r) {
        if (tag[v] == 0) return;
        d[v].first += tag[v];
        if (l != r) {
            tag[v * 2] += tag[v];
            tag[v * 2 + 1] += tag[v];
        }
        tag[v] = 0;
    }

    void update(int v, int l, int r, int L, int R, int val) {
        push(v, l, r);
        if (L > R) return;
        if (l == L && r == R) {
            tag[v] += val;
            push(v, l, r);
            return;
        }
        int mid = (l + r) >> 1;
        update(v * 2, l, mid, L, min(mid, R), val);
        update(v * 2 + 1, mid + 1, r, max(mid + 1, L), R, val);
        d[v] = max(d[v * 2], d[v * 2 + 1]);
    }

    pair<int, int> query(int v, int l, int r, int L, int R) {
        push(v, l, r);
        if (L > R) return {LLONG_MIN, 0};
        if (l == L && r == R) return d[v];
        int mid = (l + r) >> 1;
        auto t1 = query(v * 2, l, mid, L, min(mid, R));
        auto t2 = query(v * 2 + 1, mid + 1, r, max(mid + 1, L), R);
        return max(t1, t2);
    }

};

struct Point {
    int x, y, v;
};

void solve() {

    int n;
    cin >> n;
    vector<Point> p(n + 1);
    vector<int> vals;
    for (int i = 1; i <= n; i++) {
        cin >> p[i].x >> p[i].y >> p[i].v;
        vals.pb(p[i].x);
        vals.pb(p[i].y);
    }
    vals.pb(0);
    sort(all(vals));
    vals.erase(unique(all(vals)), vals.end());
    vals.pb(vals.back() + 1);   // 哨兵，保证空正方形可选

    int m = sz(vals);
    vector<vector<pair<int, int>>> g(m);
    for (int i = 1; i <= n; i++) {
        int pos_x = lower_bound(all(vals), p[i].x) - vals.begin();
        int pos_y = lower_bound(all(vals), p[i].y) - vals.begin();
        int pos_L = min(pos_x, pos_y);
        int pos_R = max(pos_x, pos_y);
        g[pos_L].pb({pos_R, p[i].v});   // 线段 [L, R] 挂在左端点上
    }

    SGT sgt(m);
    sgt.build(1, 0, m - 1, vals);

    int ans = -1, ans_l = -1, ans_r = -1;
    for (int i = m - 1; i >= 0; i--) {
        for (auto it : g[i]) {
            sgt.update(1, 0, m - 1, it.first, m - 1, it.second);
        }
        auto cur = sgt.query(1, 0, m - 1, i, m - 1);
        if (cur.first + vals[i] > ans) {
            ans = cur.first + vals[i];
            ans_l = vals[i];
            ans_r = vals[cur.second];
        }
    }

    cout << ans << endl;
    cout << ans_l << ' ' << ans_l << ' ' << ans_r << ' ' << ans_r << endl;

}

signed main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t;

    while (t--) {
        solve();
    }

}
