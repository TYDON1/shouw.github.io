D. Excellent Arrays 解题思路 ​

核心问题分析 ​

题意：称数组 a1,…,ana_1, \dots, a_na1​,…,an​ 是 good 的，如果对每个 iii 都有 ai≠ia_i \ne iai​=i。定义

F(a)=#{(i,j):1≤i<j≤n, ai+aj=i+j}F(a) = \#\{(i, j) : 1 \le i < j \le n,\ a_i + a_j = i + j\} F(a)=#{(i,j):1≤i<j≤n, ai​+aj​=i+j}

称数组是 excellent 的，如果它 good、每个 ai∈[l,r]a_i \in [l, r]ai​∈[l,r]、且 F(a)F(a)F(a) 取到所有 good 数组中的最大值。给定 n,l,rn, l, rn,l,r，求 excellent 数组的个数，对 109+710^9+7109+7 取模。

∑n≤2×105\sum n \le 2\times10^5∑n≤2×105，−109≤l≤1-10^9 \le l \le 1−109≤l≤1，n≤r≤109n \le r \le 10^9n≤r≤109。

1. 换元：把 aia_iai​ 变成 bib_ibi​

题目里 ai≠ia_i \ne iai​=i 和 ai+aj=i+ja_i + a_j = i + jai​+aj​=i+j 都在跟下标较劲，那就干脆做一步换元：

bi=ai−ib_i = a_i - i bi​=ai​−i

两个条件立刻变得清爽无比：

  • good   ⟺  \iff⟺ 所有 bi≠0b_i \ne 0bi​=0；
  • ai+aj=i+j  ⟺  bi+bj=0a_i + a_j = i + j \iff b_i + b_j = 0ai​+aj​=i+j⟺bi​+bj​=0。

于是 F(a)F(a)F(a) 就是"数组 bbb 里有多少对数互为相反数"。

2. 最大的 FFF 长什么样 ​

现在问题是：所有 bib_ibi​ 非零，怎么让互为相反数的数对最多？

假设我们用了若干组数值 ±k1,±k2,…\pm k_1, \pm k_2, \dots±k1​,±k2​,…，其中 ±kt\pm k_t±kt​ 这一组里有 ptp_tpt​ 个正的、qtq_tqt​ 个负的，那么

F=∑tptqtF = \sum_t p_t q_t F=t∑​pt​qt​

而 ∑t(pt+qt)=n\sum_t (p_t + q_t) = n∑t​(pt​+qt​)=n。因为 xyxyxy 这种乘积在"把资源集中到一组"时最大（p1q1+p2q2≤(p1+p2)(q1+q2)p_1q_1 + p_2q_2 \le (p_1+p_2)(q_1+q_2)p1​q1​+p2​q2​≤(p1​+p2​)(q1​+q2​)），所以只用一个绝对值 kkk 是最优的：所有 bi∈{+k,−k}b_i \in \{+k, -k\}bi​∈{+k,−k}。

设有 ppp 个 +k+k+k、n−pn - pn−p 个 −k-k−k，则 F=p(n−p)F = p(n-p)F=p(n−p)，在 p=⌊n/2⌋p = \lfloor n/2 \rfloorp=⌊n/2⌋ 或 ⌈n/2⌉\lceil n/2 \rceil⌈n/2⌉ 时取最大。所以：

excellent 数组   ⟺  \iff⟺ 存在某个 k≥1k \ge 1k≥1，使得每个 bib_ibi​ 都等于 +k+k+k 或 −k-k−k，且 +k+k+k 的个数是 ⌊n/2⌋\lfloor n/2 \rfloor⌊n/2⌋ 或 ⌈n/2⌉\lceil n/2 \rceil⌈n/2⌉。

（nnn 为偶数时这两个值相同，只有一种；nnn 为奇数时是两个不同的值，都要算。）

3. 值域限制翻译成对 kkk 的限制 ​

现在加上 l≤ai≤rl \le a_i \le rl≤ai​≤r，也就是 l≤i+bi≤rl \le i + b_i \le rl≤i+bi​≤r。分两种情况看：

若 bi=+kb_i = +kbi​=+k：需要 i+k≤ri + k \le ri+k≤r，即 k≤r−ik \le r - ik≤r−i。（下界 i+k≥li + k \ge li+k≥l 自动满足，因为 l≤1l \le 1l≤1 而 i+k≥2i + k \ge 2i+k≥2。）

若 bi=−kb_i = -kbi​=−k：需要 i−k≥li - k \ge li−k≥l，即 k≤i−lk \le i - lk≤i−l。（上界同理自动满足，因为 i≤n≤ri \le n \le ri≤n≤r。）

于是定义两个关键量：

R=r−n(所有下标都能取 +k 的上限),L=1−l(所有下标都能取 −k 的上限)R = r - n \quad(\text{所有下标都能取 } +k \text{ 的上限}),\qquad L = 1 - l \quad(\text{所有下标都能取 } -k \text{ 的上限}) R=r−n(所有下标都能取 +k 的上限),L=1−l(所有下标都能取 −k 的上限)

因为 +k+k+k 的最紧约束在 i=ni = ni=n（k≤r−nk \le r - nk≤r−n），−k-k−k 的最紧约束在 i=1i = 1i=1（k≤1−lk \le 1 - lk≤1−l）。令 M=min⁡(L,R)M = \min(L, R)M=min(L,R)。

4. 分两段：自由段和受限段 ​

第一段：1≤k≤M1 \le k \le M1≤k≤M。 这时每个下标都可以自由选正负，方案数与 kkk 无关：

cnt={(nn/2),n 为偶数(n⌊n/2⌋)+(n⌊n/2⌋+1),n 为奇数\text{cnt} = \begin{cases} \dbinom{n}{n/2}, & n \text{ 为偶数} \\[2mm] \dbinom{n}{\lfloor n/2 \rfloor} + \dbinom{n}{\lfloor n/2 \rfloor + 1}, & n \text{ 为奇数} \end{cases} cnt=⎩⎨⎧​(n/2n​),(⌊n/2⌋n​)+(⌊n/2⌋+1n​),​n 为偶数n 为奇数​

一共 MMM 个这样的 kkk，直接乘起来：

cpp
ans = (M % MOD) * temp % MOD;

注意 MMM 可以到 10910^9109 级别，要先取模。这一步把绝大部分的 kkk 一口气算完了——这是本题能过的关键。

第二段：k>Mk > Mk>M。 此时开始有下标被"锁死"：

  • 下标 iii 能取 +k+k+k 需要 i≤r−ki \le r - ki≤r−k，所以 i>r−ki > r - ki>r−k 的那些只能取 −k-k−k，个数是 c2=k−Rc_2 = k - Rc2​=k−R；
  • 下标 iii 能取 −k-k−k 需要 i≥l+ki \ge l + ki≥l+k，所以 i<l+ki < l + ki<l+k 的那些只能取 +k+k+k，个数是 c1=k−Lc_1 = k - Lc1​=k−L。

如果 c1+c2>nc_1 + c_2 > nc1​+c2​>n，说明有下标同时被两边锁死，彻底无解，直接停。否则剩下 cnt=n−c1−c2cnt = n - c_1 - c_2cnt=n−c1​−c2​ 个自由下标，还需要从中再挑出 ⌊n/2⌋−c1\lfloor n/2 \rfloor - c_1⌊n/2⌋−c1​ 个当正号：

if (n % 2 == 0) cur = get_C(cnt, n / 2 - c1);

5. 第二段最多跑多少轮？ ​

这是最容易担心的地方：kkk 会不会一直加到 10910^9109？

不会。从 k=M+1k = M + 1k=M+1 开始，c1c_1c1​ 和 c2c_2c2​ 里至少有一个（对应 min⁡\minmin 的那一边）会随 kkk 严格递增，每次加 111。而组合数 (cntn/2−c1)\binom{cnt}{n/2 - c_1}(n/2−c1​cnt​) 变成 000 的条件是 c1>⌊n/2⌋c_1 > \lfloor n/2 \rfloorc1​>⌊n/2⌋（下指标为负）或者 c2>⌊n/2⌋c_2 > \lfloor n/2 \rfloorc2​>⌊n/2⌋（下指标超过 cntcntcnt）。所以最多跑

O ⁣(n2)O\!\left(\frac{n}{2}\right) O(2n​)

轮就会因为 cur == 0 或 c1 + c2 > n 而退出。这就是代码里那两个 break 的意义——它们不只是优化，而是复杂度正确性的保证。

6. 复杂度 ​

阶乘和逆元预处理 O(MAX)O(\text{MAX})O(MAX) 一次搞定。每组数据：第一段 O(1)O(1)O(1)，第二段 O(n)O(n)O(n)。总计

O ⁣(∑n)O\!\left(\sum n\right) O(∑n)

∑n≤2×105\sum n \le 2\times10^5∑n≤2×105，222 秒随便过。

回头看这道 ∗2300*2300∗2300 的题，bi=ai−ib_i = a_i - ibi​=ai​−i 这一步换元几乎是决定性的：换完之后"最大化 FFF"立刻退化成一个初中难度的均值不等式，"所有 bib_ibi​ 只能是 ±k\pm k±k"这个极强的结构也就自己冒出来了。剩下的难点在于 kkk 的范围高达 10910^9109——但只要注意到"当 kkk 足够小的时候方案数根本不随 kkk 变化"，就能把无穷无尽的枚举压缩成"一段乘法 + O(n)O(n)O(n) 段暴力"。这种"大部分情况同质、只有边界附近才需要精细讨论"的分段技巧，在计数题里非常常见。

CPP 代码实现 ​

cpp
// D. Excellent Arrays

#include <bits/stdc++.h>
#define lg(x) (63 - __builtin_clzll(x))
#define all(x) (x).begin(), (x).end()
#define low_bit(x) ((x) & (-x))
#define pb push_back
#define db long double
#define int long long
#define sz(x) (int)x.size()
#define endl "\n"

using namespace std;

const int MOD = 1e9 + 7;
const int MAX = 200005;

int fact[MAX], invf[MAX];

int quick_power(int a, int b) {
    int res = 1;
    a %= MOD;
    while (b > 0) {
        if (b & 1) res = res * a % MOD;
        a = a * a % MOD;
        b >>= 1;
    }
    return res;
}

void init() {
    fact[0] = 1;
    invf[0] = 1;
    for (int i = 1; i < MAX; i++) fact[i] = fact[i - 1] * i % MOD;
    invf[MAX - 1] = quick_power(fact[MAX - 1], MOD - 2);
    for (int i = MAX - 2; i >= 1; i--) invf[i] = invf[i + 1] * (i + 1) % MOD;
}

int get_C(int n, int m) {
    if (m < 0 || m > n || n < 0) return 0;
    return fact[n] * invf[m] % MOD * invf[n - m] % MOD;
}

void solve() {

    int n, l, r;
    cin >> n >> l >> r;

    int L = 1 - l;      // 所有下标都能取 -k 的上限
    int R = r - n;      // 所有下标都能取 +k 的上限
    int M = min(L, R);

    int ans = 0, temp = 0;

    if (n % 2 == 0) {
        temp = get_C(n, n / 2);
    } else {
        temp = (get_C(n, n / 2) + get_C(n, n / 2 + 1)) % MOD;
    }

    // 第一段：k <= M，每个下标自由选正负
    ans = (M % MOD) * temp % MOD;

    // 第二段：k > M，部分下标被锁死
    for (int k = M + 1; ; k++) {
        int c1 = max(0LL, min(n, k - L));   // 被迫取 +k
        int c2 = max(0LL, min(n, k - R));   // 被迫取 -k

        if (c1 + c2 > n) break;

        int cnt = n - c1 - c2;
        int cur = 0;

        if (n % 2 == 0) {
            cur = get_C(cnt, n / 2 - c1);
        } else {
            cur = (get_C(cnt, n / 2 - c1) + get_C(cnt, n / 2 + 1 - c1)) % MOD;
        }

        if (cur == 0) break;

        ans = (ans + cur) % MOD;
    }

    cout << ans << endl;

}

signed main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    init();

    int t = 1;
    cin >> t;

    while (t--) {
        solve();
    }

}
