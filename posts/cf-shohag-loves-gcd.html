D. Shohag Loves GCD 解题思路 ​

核心问题分析 ​

题目要求我们构造一个字典序最大的数组 aaa，使得对于任意 1≤i<j≤n1 \le i < j \le n1≤i<j≤n，满足：

agcd⁡(i,j)≠gcd⁡(ai,aj)a_{\gcd(i, j)} \neq \gcd(a_i, a_j) agcd(i,j)​=gcd(ai​,aj​)

且所有 aia_iai​ 都必须来自给定的集合 SSS。

1. 条件转化与数学推导 ​

我们先考察最特殊的整除情况。 假设 i∣ji \mid ji∣j（即 iii 是 jjj 的因数），那么 gcd⁡(i,j)=i\gcd(i, j) = igcd(i,j)=i。 此时题目条件转化为：

ai≠gcd⁡(ai,aj)a_i \neq \gcd(a_i, a_j) ai​=gcd(ai​,aj​)

因为 gcd⁡(ai,aj)\gcd(a_i, a_j)gcd(ai​,aj​) 一定是 aia_iai​ 的约数，要使得它不等于 aia_iai​，唯一的办法就是 gcd⁡(ai,aj)≠ai\gcd(a_i, a_j) \neq a_igcd(ai​,aj​)=ai​。这意味着 aia_iai​ 不能整除 aja_jaj​。

推论： 如果在索引上存在整除关系 i∣ji \mid ji∣j，则在数值上必须满足 ai∤aja_i \nmid a_jai​∤aj​。

为了构造字典序最大的数组，我们希望前面的数尽可能大。对于 i∣ji \mid ji∣j，最简单且有效的满足 ai∤aja_i \nmid a_jai​∤aj​ 的方式是强制让 ai>aja_i > a_jai​>aj​。 因为如果 ai>aja_i > a_jai​>aj​，显然 aia_iai​ 不可能整除 aja_jaj​（ai,aja_i, a_jai​,aj​ 均为正整数）。

2. 构造策略 (基于除数链的深度) ​

基于上述“若 i∣ji \mid ji∣j 则 ai>aja_i > a_jai​>aj​”的贪心策略，我们需要为每个下标 iii 定义一个“层级”或“深度”。

定义 depth[i]depth[i]depth[i] 为以 iii 结尾的最长整除链的长度。 即存在序列 d1,d2,…,dkd_1, d_2, \dots, d_kd1​,d2​,…,dk​ 使得 d1∣d2∣⋯∣dk=id_1 \mid d_2 \mid \dots \mid d_k = id1​∣d2​∣⋯∣dk​=i，则 depth[i]=kdepth[i] = kdepth[i]=k。 例如：

  • depth[1]=1depth[1] = 1depth[1]=1 （序列：1）
  • depth[2]=2depth[2] = 2depth[2]=2 （序列：1 -> 2）
  • depth[4]=3depth[4] = 3depth[4]=3 （序列：1 -> 2 -> 4）
  • depth[6]=3depth[6] = 3depth[6]=3 （序列：1 -> 2 -> 6 或 1 -> 3 -> 6）

贪心分配： 如果我们按照 depth[i]depth[i]depth[i] 的值来分配 SSS 中的元素：

  • depthdepthdepth 越小（越接近根节点 1），分配 SSS 中越大的值。
  • depthdepthdepth 越大（越接近末端），分配 SSS 中越小的值。

具体做法是：

  1. 计算所有 1…n1 \dots n1…n 的 depthdepthdepth 值。
  2. 将集合 SSS 从大到小排序。
  3. 令 ai=S[depth[i]−1]a_i = S[depth[i] - 1]ai​=S[depth[i]−1] （注意 SSS 也是 0-indexed）。

3. 正确性验证 ​

我们验证一下这种构造是否满足题目原本的条件。 设 g=gcd⁡(i,j)g = \gcd(i, j)g=gcd(i,j)。显然 g∣ig \mid ig∣i 且 g∣jg \mid jg∣j。

根据 depthdepthdepth 的定义，整除关系意味着层级的增加，即 depth[g]<depth[i]depth[g] < depth[i]depth[g]<depth[i] 且 depth[g]<depth[j]depth[g] < depth[j]depth[g]<depth[j]（当 g≠ig \neq ig=i 且 g≠jg \neq jg=j 时）。

由于我们将 SSS 降序排列并按 depthdepthdepth 分配：

  • aga_gag​ 对应较小的 depthdepthdepth，所以 aga_gag​ 的值较大。
  • aia_iai​ 和 aja_jaj​ 对应较大的 depthdepthdepth，所以值较小。
  • 即 ag>aia_g > a_iag​>ai​ 且 ag>aja_g > a_jag​>aj​。

判断：

因为 aga_gag​ 严格大于 aia_iai​ 和 aja_jaj​，所以 aga_gag​ 必然严格大于 gcd⁡(ai,aj)\gcd(a_i, a_j)gcd(ai​,aj​)（因为 gcd⁡(x,y)≤min⁡(x,y)\gcd(x, y) \le \min(x, y)gcd(x,y)≤min(x,y)）。 所以 agcd⁡(i,j)≠gcd⁡(ai,aj)a_{\gcd(i, j)} \neq \gcd(a_i, a_j)agcd(i,j)​=gcd(ai​,aj​) 恒成立。

无解判定： 如果算出的最大深度 max⁡(depth)\max(depth)max(depth) 超过了集合 SSS 的大小 mmm，说明我们没有足够的数来区分这么长的整除链，此时输出 -1。

4. C++ 代码实现细节 ​

代码中使用类似于埃氏筛（Sieve）的方法来快速计算所有数的 depthdepthdepth。

  • 初始化所有 depth[i]=1depth[i] = 1depth[i]=1。
  • 对于每个 iii，更新其倍数 jjj：depth[j]=max⁡(depth[j],depth[i]+1)depth[j] = \max(depth[j], depth[i] + 1)depth[j]=max(depth[j],depth[i]+1)。
  • 这种递推保证了 depth[j]depth[j]depth[j] 正确记录了最长链。

CPP 代码实现 ​

使用每个数字的深度去寻找它当前所能填入的最大数字。

cpp

#include <bits/stdc++.h>

using namespace std;

typedef long long ll;

const int MAXN = 100005;
int depth[MAXN];

// 预处理：计算每个数字的深度（最长除数链长度）
// 类似于埃氏筛，时间复杂度 O(N log N) 或 O(N log log N) 取决于具体实现，这里是调和级数求和 O(N log N)
void create() {
    // 初始化深度为 1 (链: 1->i 本身至少长度为1，虽然题目中由1开始，但逻辑一致)
    // 实际上这里 depth[1]=1, depth[2]=2...
    for (int i = 1; i < MAXN; i++) depth[i] = 1;

    for (int i = 1; i < MAXN; i++) {
        // 枚举 i 的倍数，更新倍数的深度
        for (int j = 2 * i; j < MAXN; j += i) {
            depth[j] = max(depth[j], depth[i] + 1);
        }
    }
}

void solve() {

    int data_number, data_object;
    cin >> data_number >> data_object; // n 和 m
    vector<int> data(data_number + 1);
    vector<int> objects(data_number);

    // 读入集合 S
    for (int i = 0; i < data_object; i++) {
        cin >> objects[i];
    }

    // 将 S 从大到小排序，以便贪心地将大数分配给低深度的位置
    sort(objects.begin(), objects.end(), greater<int>());

    for (int i = 1; i <= data_number; i++) {
        // 如果当前数字需要的深度超过了集合 S 的大小，说明无法构造
        // 因为一条长为 K 的除数链至少需要 K 个不同的数字
        if (depth[i] > data_object) {
            cout << -1 << endl;
            return;
        }
        // 分配数值：深度越小，索引越小，值越大
        data[i] = objects[depth[i] - 1];
    }

    // 输出结果
    for (int i = 1; i <= data_number; i++) {
        cout << data[i] << " ";
    }

    cout << endl;

}

int main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    // 预处理 depth 数组
    create();

    int t = 1;
    cin >> t;

    while (t--) {
        solve();
    }

}
