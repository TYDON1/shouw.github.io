D. Max GEQ Sum 解题思路 ​

核心问题分析 ​

题目要求判断对于数组中所有的子区间 [i,j][i, j][i,j]，是否都满足：区间最大值 ≥\ge≥ 区间和。 即：

max⁡(ai,…,aj)≥∑k=ijak\max(a_i, \dots, a_j) \ge \sum_{k=i}^j a_k max(ai​,…,aj​)≥k=i∑j​ak​

数据范围 N≤2⋅105N \le 2 \cdot 10^5N≤2⋅105，这意味着我们需要一个 O(Nlog⁡N)O(N \log N)O(NlogN) 或 O(N)O(N)O(N) 的解法。直接枚举所有区间 O(N2)O(N^2)O(N2) 显然不可行。

1. 转换视角 (Contribution Technique) ​

与其枚举区间，不如枚举数组中的每个元素 aka_kak​，假设它是某个区间的最大值。 对于固定的 aka_kak​，我们需要找到它能作为最大值的最大范围 (Lk,Rk)(L_k, R_k)(Lk​,Rk​)。 在这个范围内，对于任意包含 aka_kak​ 的子区间 [i,j][i, j][i,j] (Lk<i≤k≤j<RkL_k < i \le k \le j < R_kLk​<i≤k≤j<Rk​)，都需要满足：

ak≥Sum(i,j)a_k \ge \text{Sum}(i, j) ak​≥Sum(i,j)

2. 确定最大值的统治范围 (单调栈) ​

我们要找到 aka_kak​ 向左和向右分别能延伸多远，且保持 aka_kak​ 是最大值。 这可以通过单调栈在 O(N)O(N)O(N) 时间内求出。

  • LkL_kLk​: 左边第一个严格大于 aka_kak​ 的位置。
  • RkR_kRk​: 右边第一个大于 aka_kak​ 的位置（处理相等元素时，一边取严格大于，一边取大于等于，以避免重复计算或遗漏，本题代码逻辑中处理的是只要 ≤\le≤ 就弹栈，即找严格大于）。

在区间 (Lk,Rk)(L_k, R_k)(Lk​,Rk​) 内，任何跨过 kkk 的子数组都以 aka_kak​ 为最大值。

3. 验证不等式 (前缀和与最值查询) ​

对于确定的 kkk 和范围 (Lk,Rk)(L_k, R_k)(Lk​,Rk​)，我们需要验证是否对于所有合法的 i,ji, ji,j，都有 Sum(i,j)≤ak\text{Sum}(i, j) \le a_kSum(i,j)≤ak​。 如果存在一个反例 Sum(i,j)>ak\text{Sum}(i, j) > a_kSum(i,j)>ak​，则输出 NO。

我们知道 Sum(i,j)=Sum(i,k)+Sum(k,j)−ak\text{Sum}(i, j) = \text{Sum}(i, k) + \text{Sum}(k, j) - a_kSum(i,j)=Sum(i,k)+Sum(k,j)−ak​（因为 aka_kak​ 被加了两次，需减去一次，或者理解为左半部分后缀和 + 右半部分前缀和）。

这里有一个关键的数学推导： 如果存在一个跨过 kkk 的区间和大于 aka_kak​，即 Sum(i,j)>ak\text{Sum}(i, j) > a_kSum(i,j)>ak​，那么必然满足以下至少一个条件：

  1. Sum(i,k)>ak\text{Sum}(i, k) > a_kSum(i,k)>ak​ （以 kkk 结尾的左侧子区间和超标）
  2. Sum(k,j)>ak\text{Sum}(k, j) > a_kSum(k,j)>ak​ （以 kkk 开始的右侧子区间和超标）

证明： 假设 Sum(i,k)≤ak\text{Sum}(i, k) \le a_kSum(i,k)≤ak​ 且 Sum(k,j)≤ak\text{Sum}(k, j) \le a_kSum(k,j)≤ak​。 那么 Sum(i,j)=Sum(i,k)+Sum(k,j)−ak≤ak+ak−ak=ak\text{Sum}(i, j) = \text{Sum}(i, k) + \text{Sum}(k, j) - a_k \le a_k + a_k - a_k = a_kSum(i,j)=Sum(i,k)+Sum(k,j)−ak​≤ak​+ak​−ak​=ak​。 这与假设 Sum(i,j)>ak\text{Sum}(i, j) > a_kSum(i,j)>ak​ 矛盾。 因此，我们只需要独立检查：

  • 在范围 (Lk,k](L_k, k](Lk​,k] 内，以 kkk 结尾的最大后缀和是否 >ak> a_k>ak​。
  • 在范围 [k,Rk)[k, R_k)[k,Rk​) 内，以 kkk 开头的最大前缀和是否 >ak> a_k>ak​。

4. 数据结构选择 ​

为了快速查询范围内的最大前缀和/后缀和，我们可以利用前缀和数组 BBB (Bi=∑x=0i−1axB_i = \sum_{x=0}^{i-1} a_xBi​=∑x=0i−1​ax​) 配合线段树。

  • 右侧检查： 我们需要找 j∈[k+1,Rk]j \in [k+1, R_k]j∈[k+1,Rk​] 使得 Sum(k,j−1)=Bj−Bk\text{Sum}(k, j-1) = B_j - B_kSum(k,j−1)=Bj​−Bk​ 最大。即查询 max⁡j∈[k+1,Rk](Bj)−Bk>ak\max_{j \in [k+1, R_k]}(B_j) - B_k > a_kmaxj∈[k+1,Rk​]​(Bj​)−Bk​>ak​。
  • 左侧检查： 我们需要找 i∈[Lk+1,k]i \in [L_k+1, k]i∈[Lk​+1,k] 使得 Sum(i,k)=Bk+1−Bi\text{Sum}(i, k) = B_{k+1} - B_iSum(i,k)=Bk+1​−Bi​ 最大。即查询 Bk+1−min⁡i∈[Lk+1,k](Bi)>akB_{k+1} - \min_{i \in [L_k+1, k]}(B_i) > a_kBk+1​−mini∈[Lk​+1,k]​(Bi​)>ak​。

线段树可以支持 O(1)O(1)O(1) 或 O(log⁡N)O(\log N)O(logN) 的区间最大/最小值查询。

5. 代码实现细节 ​

  1. 构建前缀和数组 b。
  2. 利用单调栈计算每个 iii 的左右边界 L[i]L[i]L[i] 和 R[i]R[i]R[i]。
  3. 构建线段树维护 b 数组的区间最大值和最小值。
  4. 遍历每个 iii，查询线段树验证上述两个条件。如果任意条件违反，输出 "NO"。
  5. 所有检查通过，输出 "YES"。
cpp
#include <bits/stdc++.h>
#define int long long
#define endl "\n"

using namespace std;

// 线段树节点信息，维护区间最大值和最小值
struct Info {
    int max_v = -2e18; // 初始化为极小值
    int min_v = 2e18;  // 初始化为极大值

    Info() {}
    Info(int v) : max_v(v), min_v(v) {}

    // 合并两个节点的信息
    friend Info operator+(const Info &a, const Info &b) {
        Info res;
        res.max_v = std::max(a.max_v, b.max_v);
        res.min_v = std::min(a.min_v, b.min_v);
        return res;
    }
};

// 通用线段树模板
template<class Info>
struct Segment_Tree {
    int n;
    vector<Info> info;
    Segment_Tree(): n(0) {}

    Segment_Tree(int n_, Info v_ = Info()) {
        init(n_, v_);
    }

    template<class T>
    Segment_Tree(vector<T> init_) {
        init(init_);
    }

    void init(int n_, Info v_ = Info()) {
        init(vector<Info>(n_, v_));
    }

    template<class T>
    void init(vector<T> init_) {
        n = init_.size();
        info.assign(4 << bit_width(unsigned(n)), Info());

        function<void(int, int, int)> build = [&](int p, int l, int r) {
            if (l == r) {
                info[p] = init_[l];
                return;
            }
            int m = (l + r) >> 1;
            build(2 * p, l, m);
            build(2 * p + 1, m + 1, r);
            pull(p);
        };
        build(1, 0, n - 1);
    }

    void pull(int p) {
        info[p] = info[p * 2] + info[p * 2 + 1];
    }

    // 区间查询
    Info query(int p, int l, int r, int x, int y) {
        if (l > y || r < x) {
            return Info();
        }
        if (l >= x && r <= y) {
            return info[p];
        }
        int m = (l + r) >> 1;
        return query(2 * p, l, m, x, y) + query(2 * p + 1, m + 1, r, x, y);
    }

    Info query(int l, int r) {
        if (l > r) {
            return Info();
        }
        return query(1, 0, n - 1, l, r);
    }
};

void solve() {
    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 计算前缀和数组 b，注意 b 的大小为 n+1
    // b[i] 表示 a[0]...a[i-1] 的和
    vector<int> b(n + 1);
    for (int i = 0; i < n; i++) {
        b[i + 1] = a[i] + b[i];
    }

    // 单调栈求左右边界
    vector<int> L(n), R(n);
    stack<int> s;

    // 求 L[i]: 左侧第一个 > a[i] 的位置
    for (int i = 0; i < n; i++) {
        while (!s.empty() && a[s.top()] <= a[i]) {
            s.pop();
        }
        if (!s.empty()) {
            L[i] = s.top();
        } else {
            L[i] = -1; // 边界
        }
        s.push(i);
    }

    while (!s.empty()) s.pop();

    // 求 R[i]: 右侧第一个 > a[i] 的位置
    for (int i = n - 1; i >= 0; i--) {
        while (!s.empty() && a[s.top()] <= a[i]) {
            s.pop();
        }
        if (!s.empty()) {
            R[i] = s.top();
        } else {
            R[i] = n; // 边界
        }
        s.push(i);
    }

    // 在前缀和数组上建立线段树
    Segment_Tree<Info> st(b);

    for (int i = 0; i < n; i++) {
        int val = a[i];
        
        // 检查右侧子段：Range [i, R[i]-1]
        // 对应的 b 索引范围是 [i+1, R[i]]
        // max(b[k]) - b[i] > a[i] ?
        Info r_res = st.query(i + 1, R[i]);
        if (r_res.max_v - b[i] > val) {
            cout << "NO" << endl;
            return;
        }

        // 检查左侧子段：Range [L[i]+1, i]
        // 对应的 b 索引范围是 [L[i]+1, i]
        // b[i+1] - min(b[k]) > a[i] ?
        Info l_res = st.query(L[i] + 1, i);
        if (b[i + 1] - l_res.min_v > val) {
            cout << "NO" << endl;
            return;
        }
    }

    cout << "YES" << endl;
}

signed main() {
    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    cin >> t;

    while (t--) {
        solve();
    }
}
