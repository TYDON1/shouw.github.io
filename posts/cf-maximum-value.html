B. Maximum Value 解题思路 ​

核心问题分析 ​

题意干净得不能再干净：给一个长度为 nnn 的序列 aaa，要从里面挑两个数 ai,aja_i, a_jai​,aj​（下标可以相同），在满足 ai≥aja_i \ge a_jai​≥aj​ 的前提下，最大化取模的结果

max⁡ai≥aj ai mod aj\max_{a_i \ge a_j}\ a_i \bmod a_j ai​≥aj​max​ ai​modaj​

数据范围是 n≤2×105n \le 2 \times 10^5n≤2×105，但是真正的命门在值域上：1≤ai≤1061 \le a_i \le 10^61≤ai​≤106。直接 O(n2)O(n^2)O(n2) 枚举所有数对，4×10104 \times 10^{10}4×1010 次，想都别想。看到“值域小、要取模、要枚举倍数”这几个关键词凑在一起，脑子里应该立刻蹦出四个字——调和级数。

1. 把取模翻译成“区间里挑最大” ​

我们先盯死被除数 aja_jaj​（代码里循环变量叫 it）。固定了除数 aja_jaj​ 之后，ai mod aja_i \bmod a_jai​modaj​ 这个值随 aia_iai​ 怎么变？

把整个值域按 aja_jaj​ 切成一段一段：

[aj,2aj), [2aj,3aj), [3aj,4aj), …[a_j, 2a_j),\ [2a_j, 3a_j),\ [3a_j, 4a_j),\ \dots [aj​,2aj​), [2aj​,3aj​), [3aj​,4aj​), …

在第 kkk 段 [k⋅aj, (k+1)aj)[k\cdot a_j,\ (k+1)a_j)[k⋅aj​, (k+1)aj​) 里，任意一个 aia_iai​ 模 aja_jaj​ 的结果就是 ai−k⋅aja_i - k\cdot a_jai​−k⋅aj​。也就是说——在同一段里，aia_iai​ 越大，余数越大！余数和 aia_iai​ 在段内是严格线性递增的。

所以对每一段，我们只关心一件事：这一段里实际存在的最大的那个 aia_iai​ 是谁。把它模一下 aja_jaj​，就是这一段能贡献的最大余数。把所有段、所有 aja_jaj​ 的贡献取个 max，就是答案。是不是一下子就清爽了？

2. 调和级数：为什么枚举倍数不会爆 ​

有同学要担心了：对每个 aja_jaj​ 都把值域切成那么多段，会不会很慢？

来算笔账。对一个具体的 aja_jaj​，段数大约是 106aj\frac{10^6}{a_j}aj​106​ 个。把所有去重后的 aja_jaj​ 加起来，总段数大约是

∑ajVaj≤V∑d=1V1d=V⋅H(V)=O(Vlog⁡V)\sum_{a_j} \frac{V}{a_j} \le V \sum_{d=1}^{V} \frac{1}{d} = V\cdot H(V) = O(V \log V) aj​∑​aj​V​≤Vd=1∑V​d1​=V⋅H(V)=O(VlogV)

这就是经典的调和级数求和，∑d=1V1d≈ln⁡V\sum_{d=1}^{V} \frac{1}{d} \approx \ln V∑d=1V​d1​≈lnV。V=106V = 10^6V=106 时，Vlog⁡VV\log VVlogV 大约是 2×1072 \times 10^72×107 量级，外加每段一次二分的 log⁡\loglog，完全在一秒内能跑完。注意代码开头先 sort 再 unique 去了重——这一步很关键，重复的 aja_jaj​ 没必要重复枚举，去重之后 aja_jaj​ 的种类数被压住了，调和级数的复杂度才稳。

cpp
sort(all(a));
a.erase(unique(all(a)),a.end());

3. 用二分精准捞出“每段的最大 aia_iai​” ​

知道了要找每段的最大 aia_iai​，怎么找？数组已经排好序了，二分包打天下。

看代码这个精妙的小动作：

cpp
int temp = it;
while (temp <= MAXN) {
    temp += it;
    int now = *prev(lower_bound(all(a), temp));
    max_n = max(max_n, now % it);
}

这里 it 是 aja_jaj​。循环里 temp 从 2aj2a_j2aj​ 开始，每次加 aja_jaj​，依次取到每一段的右端点 2aj,3aj,4aj,…2a_j, 3a_j, 4a_j, \dots2aj​,3aj​,4aj​,…。对于右端点 temp：

  • lower_bound(all(a), temp) 找到第一个 ≥temp\ge temp≥temp 的位置；
  • prev(...) 往前退一格，拿到的就是严格小于 temp 的那个最大的 aia_iai​——恰好是落在 [ ⋅, temp)[\,\cdot,\ temp)[⋅, temp) 这一段（及更左）里的最大值；
  • now % it 即是这个 aia_iai​ 对 aja_jaj​ 的余数，拿去更新答案。

为什么 temp 从 2aj2a_j2aj​ 起步（先 temp += it 再用）？因为 [aj,2aj)[a_j, 2a_j)[aj​,2aj​) 这一段里所有数模 aja_jaj​ 的结果，最大的也就出现在右端点 2aj2a_j2aj​ 的左边，正好被第一次循环的 prev(lower_bound(..., 2a_j)) 捞到。每个段右端点都查一次最大值，所有段扫完，这个 aja_jaj​ 的最优贡献就稳稳到手了。

小俏皮提醒：prev(begin()) 是会出事的。但这里因为 temp 至少是 2aj≥22a_j \ge 22aj​≥2，而数组里一定有 aja_jaj​ 本身（它就是 it），所以 lower_bound 绝不会落在最开头，prev 永远有得退，丝毫不影响正确性。

4. 边界与初值的小心思 ​

  • max_n 初值设成 000。因为完全可以取 ai=aja_i = a_jai​=aj​，此时 ai mod aj=0a_i \bmod a_j = 0ai​modaj​=0，答案天然下界就是 000（比如全部数都相等的退化情况，输出就是 000）。
  • while (temp <= MAXN) 用 MAXN = 1e6 + 10 卡住值域上界，保证 temp 不会无限加下去，段数被值域天花板掐断。
  • 拿样例 3 4 5 走一遍：去重还是 {3,4,5}。除数 333 时，段右端点 666，prev(lower_bound(...,6)) 拿到 555，5 mod 3=25\bmod 3 = 25mod3=2；除数 444、555 同理算下来都不超过 222。最终答案 222，和样例对上了。

整体复杂度 O(Vlog⁡V)O(V \log V)O(VlogV)（值域调和级数求和），排序去重的 O(nlog⁡n)O(n \log n)O(nlogn) 完全被它盖过，对本题数据轻松通关。

CPP 代码实现 ​

cpp
// B. Maximum Value

#include <bits/stdc++.h>
#define lg(x) (63 - __builtin_clzll(x))
#define all(x) (x).begin(), (x).end()
#define low_bit(x) ((x) & (-x))
#define pb push_back
#define db long double
// #define int long long
#define sz(x) (int)x.size()
#define endl "\n"

using namespace std;

const int MAXN = 1e6 + 10;

void solve() {

    int n;
    cin >> n;
    vector<int> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(all(a));
    a.erase(unique(all(a)),a.end());
    int max_n = 0;
    for (auto it : a) {
        int temp = it;
        while (temp <= MAXN) {
            temp += it;
            int now = *prev(lower_bound(all(a), temp));
            max_n = max(max_n, now % it);
        }
    }
    cout << max_n << endl;
    
}

signed main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    // cin >> t;
    
    while (t--) {
        solve();
    }
    
}
