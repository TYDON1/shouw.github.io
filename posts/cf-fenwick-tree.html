C. Fenwick Tree 解题思路 ​

核心问题分析 ​

题意：定义 lowbit(x)\text{lowbit}(x)lowbit(x) 为 xxx 二进制最低位的值。对长度为 nnn 的数组 aaa，定义它的树状数组变换

f(a)k=(∑i=k−lowbit(k)+1kai) mod 998244353f(a)_k = \Big(\sum_{i = k - \text{lowbit}(k) + 1}^{k} a_i\Big) \bmod 998244353 f(a)k​=(i=k−lowbit(k)+1∑k​ai​)mod998244353

再定义 fkf^kfk 为把 fff 迭代作用 kkk 次。现在给你 bbb 和 kkk，要求还原出一个 aaa 使得 fk(a)=bf^k(a) = bfk(a)=b。

n≤2×105n \le 2 \times 10^5n≤2×105，但是 k≤109k \le 10^9k≤109——这个 kkk 大得离谱，明摆着不可能真的迭代 kkk 次。多组数据，∑n≤2×105\sum n \le 2\times 10^5∑n≤2×105。

1. 把树状数组还原成一棵树 ​

第一步是把 fff 这个看起来很"位运算"的东西还原成它的本来面目。众所周知，树状数组的下标之间存在一个天然的父子关系：

parent(i)=i+lowbit(i)\text{parent}(i) = i + \text{lowbit}(i) parent(i)=i+lowbit(i)

在这个结构下，sk=∑i=k−lowbit(k)+1kais_k = \sum_{i = k - \text{lowbit}(k)+1}^{k} a_isk​=∑i=k−lowbit(k)+1k​ai​ 恰好就是「kkk 的子树内所有 aia_iai​ 之和」（包含 kkk 自己）。

所以 fff 用矩阵语言写出来就是

f=I+Uf = I + U f=I+U

其中 Uk,i=1U_{k,i} = 1Uk,i​=1 当且仅当 iii 是 kkk 的真后代。这是一个幂零（nilpotent）的严格下三角结构——树的深度有限，UUU 乘若干次就变成零矩阵。

2. 关键性质：树上路径唯一，所以 UjU^jUj 长得极其干净 ​

一般矩阵的幂会很难看，但这里有个救命的性质：每个点只有一个父亲，所以从 kkk 往下走 jjj 步到达某个具体节点 xxx 的路径，要么不存在，要么恰好只有一条。于是

(Uj)k,x=[ x 是 k 的后代，且深度恰好差 j ](U^j)_{k,x} = [\,x \text{ 是 } k \text{ 的后代，且深度恰好差 } j\,] (Uj)k,x​=[x 是 k 的后代，且深度恰好差 j]

也就是说 UjU^jUj 依然只是一个 01 矩阵，没有任何"路径计数"的爆炸。这就是这道题能做的根本原因。

3. 不求 fkf^kfk，直接求 f−kf^{-k}f−k

我们要的是 a=f−k(b)a = f^{-k}(b)a=f−k(b)，所以与其去算 fkf^kfk 再解方程，不如直接把 f−kf^{-k}f−k 求出来。

先看 f−1f^{-1}f−1 长什么样。sks_ksk​ 是子树和，那么把 sks_ksk​ 减去它所有直接儿子的子树和，剩下的就是 aka_kak​ 自己：

f−1=I−V,Vk,c=[ c 是 k 的直接儿子 ]f^{-1} = I - V, \qquad V_{k,c} = [\,c \text{ 是 } k \text{ 的直接儿子}\,] f−1=I−V,Vk,c​=[c 是 k 的直接儿子]

于是用二项式定理（III 和 VVV 显然可交换）：

f−k=(I−V)k=∑j≥0(−1)j(kj)Vjf^{-k} = (I - V)^k = \sum_{j \ge 0} (-1)^j \binom{k}{j} V^j f−k=(I−V)k=j≥0∑​(−1)j(jk​)Vj

而根据上一节的路径唯一性，VjV^jVj 就是"深度恰好差 jjj 的后代"关系。翻译成人话：

a_x = \sum_{j \ge 0} (-1)^j \dbinom{k}{j} \cdot \big(\text{x$ 的所有深度为 } j \text{ 的后代的 } b \text{ 值之和}\big)$

kkk 高达 10910^9109 完全不是问题——它只出现在组合数 (kj)\binom{k}{j}(jk​) 里，而 jjj 的范围很小。

4. jjj 到底能有多大？ ​

沿着 i→i+lowbit(i)i \to i + \text{lowbit}(i)i→i+lowbit(i) 往上走，每走一步 lowbit\text{lowbit}lowbit 至少翻倍，所以从任意节点走到根最多只需要 O(log⁡n)O(\log n)O(logn) 步。n≤2×105n \le 2\times10^5n≤2×105 时这个上界不超过 181818，代码里开到 202020 稳妥有余。

组合数 (kj)\binom{k}{j}(jk​) 也不用预处理阶乘——jjj 只有 202020 个取值，用递推一路乘过去就行：

(kj)=(kj−1)⋅k−j+1j\binom{k}{j} = \binom{k}{j-1} \cdot \frac{k-j+1}{j} (jk​)=(j−1k​)⋅jk−j+1​

cpp
int cur_C = 1;
cal[0] = 1;
for (int j = 1; j < max_j; j++) {
    if (k < j) break;                       // j > k 时组合数为 0，后面全是 0
    cur_C = cur_C * ((k - j + 1) % MOD) % MOD * inv(j) % MOD;
    cal[j] = (j & 1) ? (MOD - cur_C) % MOD : cur_C;   // 带上 (-1)^j
}

注意 kkk 本身要先取模，但 k<jk < jk<j 的判断必须用取模前的原值——否则 kkk 很大时会误判。

5. 换个方向扫：与其"往下找后代"，不如"往上找祖先" ​

公式写的是"对每个 xxx，找它深度为 jjj 的所有后代"。但直接实现这件事需要建出整棵树再做 DFS，比较麻烦。

反过来想：从每个 iii 出发往上走它的祖先链，走 jjj 步到达的那个祖先 xxx，恰好就把 bib_ibi​ 贡献给了 axa_xax​。因为祖先链是唯一的，这样扫一遍就不重不漏地覆盖了所有 (x,i,j)(x, i, j)(x,i,j) 三元组：

cpp
for (int i = 1; i <= n; i++) {
    int curr = i, j = 0;
    while (curr <= n && j < max_j) {
        if (!cal[j]) break;
        res[curr] = (res[curr] + a[i] * cal[j]) % MOD;
        curr += low_bit(curr);   // 往上跳一层
        j++;
    }
}

一行 curr += low_bit(curr) 就搞定了建树、找祖先、算深度三件事——这道题从头到尾根本不需要显式建出任何树结构，全靠 lowbit\text{lowbit}lowbit 的代数性质。

6. 复杂度 ​

外层枚举 nnn 个位置，每个位置往上跳 O(log⁡n)O(\log n)O(logn) 步，组合数预处理是 O(log⁡nlog⁡P)O(\log n \log P)O(lognlogP) 的常数级别。总复杂度

O(nlog⁡n)O(n \log n) O(nlogn)

∑n≤2×105\sum n \le 2\times10^5∑n≤2×105，333 秒时限下随便跑。

回头看这道 ∗2300*2300∗2300 的题，题面把 lowbit\text{lowbit}lowbit 摆在最显眼的位置，反而容易让人一头栽进位运算的细节里出不来。真正的破题点是那句"树状数组本质是一棵树，fff 本质是 I+UI + UI+U"——一旦把它写成矩阵，kkk 次幂就变成了二项式展开，10910^9109 这个吓人的数字瞬间蒸发成 202020 个组合数系数。而让整件事成立的技术前提，是树上父亲唯一导致的 UjU^jUj 不会退化成路径计数。这三层（树结构 → 线性算子 → 二项式反演）串起来，题就通了。

CPP 代码实现 ​

cpp
// C. Fenwick Tree

#include <bits/stdc++.h>
#define lg(x) (63 - __builtin_clzll(x))
#define all(x) (x).begin(), (x).end()
#define low_bit(x) ((x) & (-x))
#define pb push_back
#define db long double
#define int long long
#define sz(x) (int)x.size()
#define endl "\n"

using namespace std;

const int MOD = 998244353;

void solve() {

    int n, k;
    cin >> n >> k;
    vector<int> a(n + 1);
    for (int i = 1; i <= n; i++) cin >> a[i];

    auto qpow = [&](int base, int exp) {
        int res = 1;
        base %= MOD;
        while (exp > 0) {
            if (exp & 1) res = res * base % MOD;
            base = base * base % MOD;
            exp >>= 1;
        }
        return res;
    };
    auto inv = [&](int x) { return qpow(x, MOD - 2); };

    // cal[j] = (-1)^j * C(k, j)，j 最多到树高 O(log n)
    int max_j = 20;
    vector<int> cal(max_j, 0);
    cal[0] = 1;
    int cur_C = 1;
    for (int j = 1; j < max_j; j++) {
        if (k < j) break;
        cur_C = cur_C * ((k - j + 1) % MOD) % MOD * inv(j) % MOD;
        cal[j] = (j & 1) ? (MOD - cur_C) % MOD : cur_C;
    }

    vector<int> res(n + 1, 0);
    for (int i = 1; i <= n; i++) {
        int curr = i, j = 0;
        while (curr <= n && j < max_j) {
            if (!cal[j]) break;
            res[curr] = (res[curr] + a[i] * cal[j]) % MOD;
            curr += low_bit(curr);
            j++;
        }
    }

    for (int i = 1; i <= n; i++) cout << res[i] << " ";
    cout << endl;

}

signed main() {

    ios_base::sync_with_stdio(false);
    cin.tie(nullptr);

    int t = 1;
    cin >> t;

    while (t--) {
        solve();
    }

}
